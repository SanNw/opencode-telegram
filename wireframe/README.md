# Wireframe package

Open `index.html` in a browser to inspect the canonical interactive reference.

## Important

The Tailwind browser CDN is used only to make this reference package easy to open locally. The production application should use the project's normal Tailwind build pipeline rather than relying on the CDN.

## Reference priority

1. `../PROJECT_SPEC.md` — product, architecture, security and acceptance criteria.
2. `WIREFRAME_SPEC.md` — normative visual/UX rules.
3. `index.html` — concrete interactive visual reference.

If production constraints require a deviation, preserve the visual identity and document the reason rather than silently redesigning the interface.
